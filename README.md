Referral-clean update

Features:
- User Panel Refer button with Telegram native Copy Referral Link button.
- Default user referral commission: fixed 0.05 BDT per Green UID.
- Default commission can be fixed or percentage of the Green UID payout.
- Admin-designated referrers do NOT receive default/user commission.
- Admin Green Commission is configured per admin and per category.
- Admin Green Commission supports fixed amount or percentage per Green UID.
- Referral Management submenu:
  1. Refer Statistics
  2. Enable/Disable User Commission
  3. Enable/Disable Admin Commission
  4. Set Default Commission
  5. Set Admin Green Commission
  6. List Admin Commission
- Existing bot features are preserved from the supplied base bot.

Install dependencies from requirements.txt before running buyerbotv1.py.
